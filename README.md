# 🦀 Rust Profile

![Rust](https://img.shields.io/badge/Rust-1.97-orange)
![Status](https://img.shields.io/badge/Status-Em%20Desenvolvimento-green)

Projeto desenvolvido durante meu aprendizado da linguagem **Rust**.

O objetivo deste repositório é acompanhar minha evolução na linguagem através de exercícios, experimentos e pequenos projetos práticos.

> 🚧 Este repositório está em constante evolução. Novos conceitos serão estudados e aplicados ao projeto progressivamente.

## 🎯 Objetivo

O projeto começou como uma aplicação simples para praticar os fundamentos de Rust e será evoluído conforme novos conceitos da linguagem forem aprendidos.

A ideia é transformar gradualmente um programa simples em uma aplicação mais completa, aplicando os recursos da linguagem conforme eles forem estudados.

## 📚 Conteúdos estudados

Até o momento, foram praticados:

* Variáveis
* Mutabilidade
* Shadowing
* Tipos básicos
* `&str`
* `bool`
* `i32`
* `u8`
* `f64`
* Conversão de tipos com `as`
* Conversão com `parse()`
* Operadores aritméticos
* Operadores de comparação
* Operadores lógicos
* `if`
* `else`
* `else if`
* `if` como expressão

Esta lista será atualizada conforme novos conceitos forem estudados.

O projeto será desenvolvido de forma incremental.
