# 🦀 Rust Profile

![Rust](https://img.shields.io/badge/Rust-1.97-orange)
![Status](https://img.shields.io/badge/Status-Em%20Desenvolvimento-green)

Projeto desenvolvido durante meu aprendizado da linguagem **Rust**.

O objetivo deste repositório é acompanhar minha evolução na linguagem através de exercícios, experimentos e pequenos projetos práticos.

> 🚧 Este repositório está em constante evolução. Novos conceitos serão estudados e aplicados ao projeto progressivamente.

---

## 🎯 Objetivo

O projeto começou como uma aplicação simples para praticar os fundamentos de Rust e será evoluído conforme novos conceitos da linguagem forem aprendidos.

A ideia é transformar gradualmente um programa simples em uma aplicação mais completa, aplicando os recursos da linguagem conforme eles forem estudados.

## 🚀 Evolução do projeto

O projeto será desenvolvido de forma incremental.

### v1.0 — Perfil básico

Primeira versão do projeto utilizando:

- Variáveis
- Tipos básicos
- Operadores
- Conversão de tipos
- Condicionais
- Validação de maioridade
- Controle de pontos
- Verificação de autorização

### v1.1 — Perfil interativo

Implementação de entrada de dados pelo terminal.

Funcionalidades:

- Leitura do nome do usuário
- Leitura da idade
- Utilização de `std::io`
- Utilização de `stdin()`
- Utilização de `read_line()`
- Remoção de espaços e quebras de linha com `trim()`
- Conversão da idade com `parse::<u8>()`
- Tratamento de entrada inválida com `Result`
- Utilização de `match`
- Repetição da entrada de idade com `loop`
- Separação da leitura em funções

### Próximas versões

Novas funcionalidades serão adicionadas conforme novos conceitos de Rust forem aprendidos.

Entre os próximos conteúdos estão:

- Strings e manipulação de texto
- Ownership
- Borrowing
- References
- Structs
- Métodos
- Enums
- `Option`
- Traits
- Collections
- Iterators
- Closures
- Módulos
- Testes
- E outros recursos da linguagem

A ordem e o conteúdo das próximas versões poderão mudar conforme a evolução do aprendizado.

## 🧪 Execução

Para executar o projeto:

```bash
cargo run
```

Para verificar se o código compila:

```bash
cargo check
```

Para formatar o código:

```bash
cargo fmt
```

## 📌 Git Workflow

O desenvolvimento também é utilizado para praticar um fluxo de trabalho baseado em Git:

```text
Issue
  ↓
Branch
  ↓
Implementação
  ↓
Testes
  ↓
Commit
  ↓
Push
  ↓
Pull Request
  ↓
Review
  ↓
Merge
  ↓
Main
```

Cada nova funcionalidade deverá, sempre que possível, estar relacionada a uma Issue e ser desenvolvida em uma branch própria.
